# app: 棋譜の誤記を直す・指摘する（`kifufix.go` / `kifufixshelf.go`）— **2026-11-19**

ふわりと将棋の棋譜速報は手で書いた KI2 なので、記録の誤記が混じる。解析タブの手順リストで直し、
直した本譜は棚へ**訂正版**（kicho の派生棋譜）として親子で入れ、反則手は ikkyoku が見つけて kicho の**指摘**にする。
なぜこの形にしたかは `_docs/design-position.md` の「棋譜の誤記を直す」。画面は `_docs/ui/moves.md` の「原本の ⚠ の行と直し」。

## 呼び名

画像の局面を直す「**訂正タブ**」と混ざるので、ikkyoku の中では次のように呼ぶ。
⚠️ **「訂正」を手順リストの操作名に使わない**（訂正タブの操作と区別が付かなくなる）。

| 呼び名 | 何か |
|---|---|
| **直す / 直した手** | 手順リストで原本の手を別の手にすること / その手 |
| **原本** | 取得元・棚にある棋譜そのもの（kicho の親）。`position.Original` |
| **訂正版** | 直した本譜を棚に入れたもの（kicho の子。関係は `correction`） |
| **指摘** | kicho の `Flag`。「この手が違う」という印。本文は変えない |

## 誤記の種類と、誰が見つけるか

| 誤記 | 例 | 誰が見つけるか |
|---|---|---|
| 盤に当てられない手 | 動かせる駒が無い・絞れない・表記が読めない | kicho（エラーの印 `Record.ErrorMove`）と ikkyoku（`Stop.Illegal == false`） |
| 盤には当たるが実際と違う手 | 打ち間違いがたまたま指せる手になっている | **人**（どちらにも分からない） |
| 反則手 | 二歩・王手放置・打ち歩詰め・持っていない駒を打つ | **ikkyoku**（`Stop.Illegal == true`。合法手の判定は `legal` だけ） |

## 直しの表（`kifuFixState.fixes`）

- ⚠️ **原本を読む 4 つの道は全部、表を当ててから据え直す**（`readOriginal` → `mergeReloadLocked`）——
  読み込み（`loadKifuFrom`。根が変わるので表は空）・再読み込みと自動更新（`reloadKifu`）・棚から開き直す（`graftKifu`）・
  直しを変えたとき（`rebuildLocked`）。**分けると片方だけ直しが消える**（取り直しの `Graft` は原本の手を本譜へ据え直すので）
- ⚠️ **手数は原本の手数**（`KifuFix.Move`）。直したあとの手数で持つと、足す・飛ばすを取り消したときに後ろの直しが別の手を指す
- ⚠️ **当てる前に原本の表記を比べ、違えば外して 1 回だけ知らせる**（`takeBuiltLocked` が表から消し、`KifuLoad.Note` に出す）。
  ⚠️ **黙って外さない**
- ⚠️ **根を入れ替えたら表を捨てる**（`newSessionLocked` が `fix` ごと捨てる。残っていると別の棋譜に当たる）
- ⚠️ **直した手を推測の手（橙）と同じ扱いにしない**（推測は後の 1 枚で差し替えてよいが、直しは人が言った手）
- 控え（`StudyRecord`）に**原本の本文・表・外した指摘・登録した本譜**を書く（`Original` / `Fixes` / `Dismissed` / `Registered`）。
  開き直したら原本を読み直して `built` を作り直す（⚠️ **木は控えのまま**。据え直すのは棋譜を読み直したとき）。
  ⚠️ **原本の本文は読み直すための控えで、交換形式ではない**
- 設計原則1（履歴に依存しない）は崩れない —— 表は「この原本をこう読む」という人の指示で、無くても原本どおりに読めるだけ

## 項目と印（`fixActionsLocked` / `moveMarksLocked` / `kifuStopLocked`）

- ⚠️ **出す条件はここ 1 か所**（`StudyState.MoveActions` / `KifuStop.Actions`）。フロントで手数を比べない。
  `FixMove` も**出している項目だけを通す**（画面の古い表示から押されても別の手を直さない）
- ⚠️ **「直しにする」は原本を持つ検討だけ**（撮った局面・新規対局には `fix.original` が無いので何も出ない）
- ⚠️ **本譜が原本の並び（`Built.Plies`）と揃っているところまでしか印も項目も出さない**（`alignedLocked`）——
  人が本線を選び直すなどして本譜が原本と違えば、そこから先はどの原本の手か分からない
- ⚠️ **取り消した直しの手は人が指した枝として残す**（`demoteUnfixedLocked`。原本の手が生えずに本譜に残ったら `Branch` で下げる）
- ⚠️ **自分の枝が黙って本譜になる道を作らない** —— 本譜が変わるのは人が右クリックで言ったときだけ

## 指摘

- 人が付ける: 手順リストの「指摘する…」（`KifuService.FlagMove`。`By` は `"user"`）。⚠️ **棚の棋譜だけ**（付け先の id が要る）
- **棚の棋譜を読んで反則手で止まったら、その手に指摘を付ける**（`autoFlagIllegal`。`By` は `"ikkyoku"`）
  - ⚠️ **同じ指摘を重ねない**（同じ手に古くない ikkyoku の指摘があれば付けない。開くたび・取り直すたびに増える）
  - ⚠️ **人が外した指摘を付け直さない**（`dismissFlag`。原本のその手の表記が同じあいだ。実際に指された反則手で
    反則負けになった対局は、記録として正しい）
  - ⚠️ **kicho のエラーの印がある手には付けない**（二重に出さない）
  - ⚠️ **付けられなくても読み込みは止めない**（設計原則3）
- ⚠️ **指摘をエラーの印へ寄せて書かないこと**（kicho の約束。あちらは取り直しで消える）
- 指摘の読み直しは棋譜を読んだあと（`afterKifuRead`）と指摘を変えたあと（`flagsChanged`）。⚠️ **どちらもロックの外**（棚を読む）

## 訂正版として登録（`KifuService.saveCorrection`）

- 口は今の「棋譜に登録」と同じ**投了の行の右クリック**。直した手があれば項目名が「訂正版として登録」になる（`RegisterLabel`）
- `registerableLocked` は**直した手があれば**、棚と結んでいても URL から読んでいても通す（親子で入るので）。
  ⚠️ **終局していなければ断る**（対局中の子は作らない —— 親は取り直すたびに伸びるが、子は固定）・
  ⚠️ **同じ本譜で 2 度登録しない**（`fix.registered`）
- 親は**原本**。棚に無ければ先に入れる（出どころの鍵があれば取り直して `Library.Save`、無ければ貼り付けとして `ImportKIF`）
- 子は直した本譜の KIF（`SaveDerived(親, correction, …)`）
- **盤に当たる誤記を置き換えた手には、親に指摘も付ける**（「実際は △…」。盤に当たらない誤記は kicho のエラーの印が既にある）
- ⚠️ **検討は親と結んだまま**にする（仕様の段階では子と結ぶ案だったが、直しの表は親の控えにあり、直し直すのは親から開くため。
  子は普通の KIF で表を持たない）
