# ikkyoku を実機で確認する

**ここは「何を押すか」と「どう見るか」の置き場。** 設計上の制約は `AGENTS.md`
（と各パッケージの AGENTS.md）にあり、**このスキルには制約を書かない** ——
制約は触ったときに自動で読まれる場所に無いと守れない。

⚠️ **このプロジェクトは「型とビルドが通った」を根拠にできない。** 効いているのは
ウィンドウの寸法・DPI・重ねたグリッドの座標・WebView2 の状態といった、
**コンパイラが何も言わない層**が多い。だから未検証リストを持っている。

## 進め方

1. **`references/checklist.md` を読む。** 機能ごとに並んでいて、各項目の頭に
   ⚠️ が付いているものが**壊れると気づけない**もの。**上から順に危ない**ように
   書いてあるので、その順で押す
2. **ビルドして起動する**（下記）
3. **確かめたら `checklist.md` から消して `references/verified.md` へ移す。**
   ⚠️ **消すだけにしないこと** —— 何を確かめたのかが残らないと、同じところを
   何度も見ることになる

⚠️ **チェックリストを AGENTS.md に戻さないこと。** 読む場面が実機確認のときだけなのに
**実装のたびに増える**ので、戻すと元の 772 行に戻る（2026-09-09 にここへ移した）。
4. **壊れていたら直す。** そのとき ⚠️ の理由を `AGENTS.md` 側に足す
   （「実際に踏んだ」と書いてある行はすべてこうして増えたもの）

```powershell
cd ikkyoku\_cmd\ikkyoku
npm --prefix frontend install         # 初回のみ
wails3 generate bindings -ts -i       # frontend/bindings は生成物。クローン直後は無い
wails3 build                          # frontend ビルド〜go build まで
Start-Process .\bin\ikkyoku.exe
```

- ⚠️ **`wails3 dev` では確かめられないものがある**（焼き込み `-tags embedmodel` は
  dev に渡せない）。認識器の焼き込みを見るときは `task build:embed` した exe を直接起動する
- ⚠️ **起動し直すときは古いプロセスを必ず落とすこと。** 単一インスタンスの防止を
  入れていないので 2 つ走り、`app-window.json` の二重書き込み・ホットキー登録・
  エンジンのプロセスが重なる

## 確かめ方（手法。**使い回せる**）

### 1. 画面全体を撮って目視する

**GUI 自身のガイド枠を画面いっぱいに広げてキャプチャし、撮れた PNG を見る。**
枠の写り込み・透過・重なりはこれで分かる。

### 2. HWND から矩形を取り、ピクセル値を調べる（**目視より確実**）

アプリを起動 → HWND から矩形を直接取得 → その矩形をスクリーンショットから切り出して
ピクセルを数える。**撮った PNG の外周 2px に赤（`#E93D3D` 系）が 0 個であること**を
確かめるのに使った。呼ぶのは `GetClientRect` + `ClientToScreen` + `GetDpiForWindow` だけ。

⚠️ **検証用スクリプトを PowerShell で書くときは注意。** PowerShell は DPI 非対応
プロセスなので座標が仮想化され、**per-monitor DPI aware な Wails アプリと座標系が
食い違う**。

### 3. ハーネスで描画だけ確認する

**bindings をスタブに差し替えたページをブラウザで開く。** 評価値グラフの目盛り・
勝率バーの見え方・駒台に何枚入るか・「足りない駒」を続けて置けるかは、これで
実機を起こさずに詰められる（実際そうやって確かめた項目が `verified.md` にある）。

⚠️ **これで済むのは描画とマウス操作だけ。** ウィンドウ・DPI・WebView2 の状態・
エンジンのプロセス・棚（SQLite）は**実機でしか確かめられない。**

### 4. ログを読む

- **心拍**（`DiagService.Heartbeat`。5 秒ごと）。⚠️ **メイン画面が真っ黒になったら、
  何かを押す前にこれを見る** —— 続いているか止まっているかで手当てが変わる
  （`AGENTS.md` の「メイン画面が真っ黒になって触れなくなる」）
- **ウィンドウの表示状態**（`registerVisibilityLog`）は debug なので既定では出ない。
  追うときだけ Level を上げる
- **同梱エンジンは USI の送受信を全部 `slog.Info` に出す**ので、解析すると info が流れる
