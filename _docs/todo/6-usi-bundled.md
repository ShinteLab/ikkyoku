# `usi/` の位置づけを実態に合わせる（「Step 2 で消える足場」ではなくなっている）

2026-11-13 の全体の見直しで出た点。**まだ直していない。文書の直しが中心で小さい。**
終わったらこの文書を消し、`TODO.md` 7 の行を消す。

## 何が食い違っているか

文書は `ikkyoku/usi` を「Step 1 の足場。Step 2（外部エンジン）で消える」と書いている。書いてある場所は 4 つ:

- `usi/AGENTS.md`（全体）
- ルートの `AGENTS.md` の「モジュール / 位置づけ」の `engine` の行（「①Step 1 の足場（`usi/local.go`。Step 2 で消える）」）
- ルートの `AGENTS.md` の「ファイル構成」の `usi/` の行
- `analyze/AGENTS.md` の「層の分け方」の `ikkyoku/usi` の行

実態:

- 外部エンジン（Step 2）はもう入っている（複数エンジン・MultiPV・詰み探索）
- それでも**同梱エンジンは今もここを通る**。`analyze/analyze.go` が `localusi.Local(ctx)` で繋いでいる
- ルートの `AGENTS.md` の「崩さないこと」に「⚠️ 攻方の玉が無い局面は同梱エンジンにしか渡さない」がある。
  つまり同梱エンジンは**消える予定の足場ではなく、決定が依存している部品**

読んだ人（エージェント）が「消える予定だから手を入れない」「消してよい」と判断しうるのが害。

## ⚠️ 先にユーザーに確かめること

**同梱エンジンを残すのは決定か。** 上の「攻方の玉が無い局面は同梱エンジンにしか渡さない」からは残す前提に読めるが、
「Step 2 で消える」を取り下げた記録は見つけていない。残すなら下の直しをする。いつか消すつもりなら、
「消える」の条件（何が入れば消せるか）を書く形に直す。

## 直すこと（残すと決まった場合）

1. **`usi/AGENTS.md` を書き直す。** 「同梱エンジンの口。同一プロセスの `engine` を `io.Pipe` で USI として繋ぐ。
   外部エンジンと同じ USI クライアント（`core/usi/client`）から見えるようにするための層」。今ある 2 つの制約は残す:
   - `localEngine` は `engine.ContextEngine` の実装（これがあるから `stop` が効く）。`engine/_samples` は import しない
   - ⚠️ Lazy SMP（`Parallel`）は使わない（worker の goroutine の panic でアプリごと落ちる）
2. **ほかの 3 か所の「Step 2 で消える」を外す。** ルートの `AGENTS.md` の `engine` の行は
   「①同梱エンジン（`usi/local.go`）②合法手生成（`legal/`）」に。⚠️ **「解析を engine の直呼びに戻さないこと」は残す**
   —— 同梱エンジンも USI 越しに使う、というのがこの決定の中身
3. **`_docs/design-engine.md` に 1 項目**（日付つき）。「同梱エンジンは残す。理由: 外部エンジンを入れていない人でも解析が動く
   （設計原則3）・攻方の玉が無い局面を渡せるのは同梱だけ」。理由はユーザーの答えに合わせる
4. **名前は変えない。** `ikkyoku/usi` は `core/usi` と紛らわしいが（`analyze` は `localusi` と別名で import している）、
   改名は import を変えるだけで得るものが少ない

## テスト

`usi/` にテストファイルは無い（`go test ./...` で `[no test files]`）。ただし `analyze/analyze_test.go` が
`localusi.Local(ctx)` で同梱エンジンを実際に起こして 1 局面を解析しているので、**繋がることは確かめられている**
（`analyze/AGENTS.md` の「テスト」節に「`io.Pipe` 越しの同梱エンジン相手」とある）。

`stop` が効くこと（`localEngine` を `ContextEngine` にしている理由そのもの）も、`analyze/analyze_test.go` が
打ち切りのテスト（50ms で切って `Stopped` を見る）で見ている。**そのテストが同梱エンジン相手に走っていることを読んで確かめ、
そうならテストは足さない。**
