# _cmd/ikkyoku-trim の AGENTS.md

**録画した動画を「盤が変わった前後だけ」に詰めるコマンド**（2026-10-11）。使い方・仕組み・区間の JSON・確かめたこと・
決まっていないことは **`README.md`**。ここは触るときの制約だけ。

ikkyoku のルートモジュールの中の、**Wails を使わない普通の Go のコマンド**。`_cmd` の下なので `go build ./...` の対象外。
**ikkyoku アプリ（`_cmd/ikkyoku`）とは関わらない** —— 動画を詰めるだけの道具で、アプリの側にこのための口は無い。

```bash
GOWORK=off go run ./_cmd/ikkyoku-trim [フラグ] <動画ファイルかディレクトリ>...
GOWORK=off go test ./_cmd/ikkyoku-trim
```

| ファイル | 役割 |
|---|---|
| `main.go` | フラグと段取り（1 段目 → JSON → 2 段目） |
| `input.go` | 入力を並べる（ファイル・ディレクトリ）・ffprobe で大きさ・長さ・コマ数・最初の時刻を調べる |
| `scan.go` | **1 段目**: ffmpeg でデコードしたコマを 1 つ前のコマと比べ、変化を集める（`ikkyoku.FrameDiff`・`recognize.DetectRegion`） |
| `plan.go` | 区間の組み立て（`buildSegments`）と JSON |
| `cut.go` | **2 段目**: 区間を ffmpeg の `select` に渡して 1 本に書き出す |

## ⚠️ 崩さないこと

- ⚠️ **ikkyoku アプリと結び付けない**。借りるのはルートパッケージの `ikkyoku.FrameDiff` と `recognize.DetectRegion` だけで、
  アプリの側にこのコマンドのための口を足さない
- ⚠️ **動画を丸ごと展開しない**。1 段目が持つのは 1 つ前のコマと今のコマだけ（`decodeFrames` はバッファ 2 つを入れ替えて
  使い回す）、2 段目は ffmpeg が流しながら処理する。メモリは録画の長さに関係なく一定。⚠️ **録る長さを制約にしない**
  （ふだんは 2 時間ほどの見込みだが、もっと長く録ることもある）
- ⚠️ **ffmpeg / ffprobe は外部のコマンドとして呼ぶ**（cgo で繋がない。PureGo の方針）
- ⚠️ **変化の線は迷ったら敏感な側に倒す**（`defaultThreshold`）。余分に拾っても動画が数秒長くなるだけだが、
  見落とした変化は詰めた動画から消えて戻らない
- ⚠️ **1 つ前のコマとの比べは動画の境目をまたいで続ける**（分けて録ったあいだに盤が変わっていれば、それも変化）。
  比べられない（大きさが違う）ときは変化に倒す
- ⚠️ **画面が切り替わって盤を探し直すあいだも、前の盤の矩形で測り続ける**（捨てると探せないあいだの変化が消える）。
  矩形を捨てるのは、画面の大きさが違う動画に変わったときだけ
- ⚠️ **区間の時刻に動画の最初の時刻（`StartTime`）を足して切る**（mpeg-ts などは 0 から始まらない）
- ⚠️ **ディレクトリを読むとき、書き出した動画（名前の終わりが `-trim`）を拾わない**（同じディレクトリに書き出すので、
  やり直すたびに前の出力が入力に混ざる）
- ⚠️ **既にある書き出し先は `-force` が無ければ上書きしない**
- ⚠️ **フィルタはファイルで渡す**（`-/filter_complex`）。区間が何百もあると Windows のコマンドラインの長さの上限を超える

## テスト（`trim_test.go`）

⚠️ **ここに書いてあるのは「何の歯止めか」。**

- `TestExpandInputs` —— ディレクトリは名前の順・書き出した動画と動画でないものとサブディレクトリは拾わない・並べたファイルは渡した順
- `TestBuildSegments` —— 前後を残す・重なる区間はまとめる・録画の外は切る・動画の境目で分ける
- `TestParseProbe` —— ffprobe の答え（`30000/1001`・最初の時刻）を読む
- `TestCutArgs` —— 区間の時刻に最初の時刻を足す・大きさの違う動画は最初の動画に合わせる・区間の無い動画は読まない
- `TestTrimEndToEnd` —— **ffmpeg で作った 2 本を 1 本の続いた録画として詰める**（境目では変化と見なさず、3 秒と 8 秒の
  変化の前後だけの 1 本になる）。ffmpeg が無ければ飛ばす
