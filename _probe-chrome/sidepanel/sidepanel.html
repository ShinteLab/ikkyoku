ikkyoku — 中継盤面診断 (Phase 0)

ABEMA将棋中継から盤面情報をどう取れるか、安い順に 4 経路を診断します。

対象タブ: 取得中…

1. 通信の傍受 最優先

WebSocket / fetch / XHR を記録します。盤面らしき JSON が流れていれば、 画像認識は一切不要になります。ここで勝てるのが最良です。

2. DOM の走査

盤面が DOM / Canvas 要素として描かれていないかを調べます。

3. タブのキャプチャ

chrome.tabs.captureVisibleTab で画面全体を撮ります。

4. video 要素のキャプチャ DRM注意

ページ内の <video> を canvas に drawImage します。 DRM (Widevine/EME) 保護時は黒フレームか SecurityError になる可能性が高いです。
